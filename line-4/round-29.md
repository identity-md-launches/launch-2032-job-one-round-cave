# The Unbroken Link

OAuthCheck extends the line's unchanged goal: identify breaking OpenAPI changes before an integration upgrade. It detects potential disruption to declared OAuth acquisition flows and endpoint URLs while keeping inherited schema, symbolic-security and transport findings. Invalid effective scope declarations refuse comparison instead of producing a misleading pass.

Run `python3 -B line-4/tools/oauthcheck/oauthcheck.py demo` from the repository root. This is fully offline and standard library only. The bundled real IMD capture is the baseline; its OAuth migration is hypothetical. Sixteen new tests and eleven existing SchemeCheck regressions passed. The public capture compared to itself has five operations and no findings. No fresh service behavior is claimed.

Known limits: all old flows offering a requirement's scopes are preserved conservatively; a different surviving grant kind does not guarantee an old client's acquisition procedure works. URL strings are compared literally, without resolving relative references or checking redirects. Discovery, actual authorization and full schema compatibility remain outside this model. See the tool README for exact limits and exits.
